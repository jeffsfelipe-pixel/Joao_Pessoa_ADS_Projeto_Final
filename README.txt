PROJETO: JOÃO PESSOA - SITE TURÍSTICO
Curso: Análise e Desenvolvimento de Sistemas (ADS)

==================================================
1. OBJETIVO DO TRABALHO
==================================================
Criar um site simples sobre a cidade de João Pessoa utilizando
HTML, CSS e JavaScript, com os arquivos separados e integrados.

==================================================
2. ESTRUTURA DO PROJETO
==================================================
index.html
    -> Página Home, com apresentação e chamadas para as outras páginas.

praias.html
    -> Página com 3 praias de João Pessoa:
       - Praia de Tambaú
       - Praia do Bessa
       - Praia do Seixas

pontos-turisticos.html
    -> Página com 3 pontos turísticos:
       - Centro Histórico
       - Centro Cultural São Francisco
       - Farol do Cabo Branco

style.css
    -> Arquivo responsável pelo visual e layout de todas as páginas.

script.js
    -> Arquivo JavaScript responsável pelo menu responsivo.

==================================================
3. COMO ABRIR O PROJETO
==================================================
PASSO 1:
Baixe o arquivo ZIP e extraia em uma pasta do computador.

PASSO 2:
Abra a pasta do projeto.

PASSO 3:
Clique duas vezes no arquivo "index.html".
O site será aberto no navegador.

PASSO 4:
No menu superior, clique em "Praias" e "Pontos turísticos"
para testar a navegação entre as três páginas.

PASSO 5:
Para estudar o código, abra os arquivos no VS Code ou outro
editor de código.

==================================================
4. COMO O HTML, CSS E JAVASCRIPT ESTÃO INTEGRADOS
==================================================
Cada página HTML possui esta linha dentro do <head>:

<link rel="stylesheet" href="style.css">

Ela conecta o HTML ao arquivo de estilos.

Também possui:

<script src="script.js" defer></script>

Ela conecta o HTML ao JavaScript.

Assim, os três arquivos trabalham juntos.

==================================================
5. O QUE O JAVASCRIPT FAZ
==================================================
O JavaScript foi usado de maneira simples para abrir e fechar
o menu de navegação quando o site é acessado em telas menores,
como celulares.

==================================================
6. IMAGENS
==================================================
As imagens do site são carregadas por links externos.
Por isso, é necessário estar conectado à internet para
visualizá-las corretamente.

==================================================
